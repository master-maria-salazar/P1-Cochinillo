INSPIRACIÓN DEL PROYECTO

Web de referencia

Para la elección de la temática de este proyecto he tomado como referencia la web de El Cochinillo Segoviano S.L., dedicada a uno de los productos gastronómicos más representativos de Segovia.

Se trata además de un proyecto con el que tengo una vinculación personal, ya que trabajé durante un año como SEO Consultant en esta web. Fue un proyecto que disfruté especialmente y por ese motivo me pareció interesante recuperar esta temática para desarrollar esta práctica.

La web se ha utilizado únicamente como referencia temática. El diseño, la estructura, los textos y los recursos visuales de este proyecto han sido creados específicamente para esta práctica.

Puedes consultar la web original aquí: El Cochinillo Segoviano S.L.

RECURSOS VISUALES

Imágenes

Todas las imágenes utilizadas en este sitio web han sido generadas mediante herramientas de inteligencia artificial.

Se ha optado por crear imágenes específicas para el proyecto porque no dispongo de licencias de uso para fotografías profesionales de cochinillo y gastronomía. De esta forma se evita utilizar imágenes de terceros sin la autorización o licencia correspondiente.

Las imágenes se han generado expresamente para ilustrar las diferentes secciones y recetas de esta práctica.
